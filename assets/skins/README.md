# Original Avni skin previews

Graphite LCD, Silver Blue and Amber Terminal are original Avni built-in skin artwork, distributed under this repository's MIT license. No historical third-party skin artwork is included.

The JPEGs are cropped browser captures of the existing 275×116 preview canvases produced by `buildMinis()` in the Avni concept site's `js/main.js`, website source commit `514e59b8e81d98fb143635c469c3487231aceed4`. The browser displayed each preview at 334×141 pixels with pixelated image rendering. They compose the site's original sprite assets and fictional track information. They are static illustrations, not screenshots of an installed application or evidence of actual provider playback.

Mint Cassette is a separate concept skin and is not advertised here as bundled with the app.
